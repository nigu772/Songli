# Songli

Mobile-first Event-Musik-Webapp mit Node.js, Express, SQLite und Spotify-Suche.

## Lokal
npm install
npm start

## Render
Build: `npm install`
Start: `npm start`

## Environment
`SESSION_SECRET`, `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `ADMIN_USERNAME`, `ADMIN_PASSWORD` setzen.

Event-Code: exakt 4 Ziffern. Creator-Passwort: mindestens 6 Zeichen.
